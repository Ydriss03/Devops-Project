# Log Archive Tool

## Overview:
 The Goal is to build a tool to archive logs on a define schedule by compressing and storing them in a new directory 


## Tools/Technologies:
  - Linux OS and Utilities 
  - VIM
  - Shell Scripting 
  - Git 

## Requirements:


### Variant 1:
 Here the script will be executed manually from the CLI using: 

```
  log-archive /var/log
```  
with /var/log being the argument and log-archive the command
You need to make the script executable `` chmod +x``
